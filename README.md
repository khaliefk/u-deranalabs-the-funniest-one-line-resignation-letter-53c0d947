# The Funniest One-Line Resignation Letter

A one-line resignation letter written in the voice of a cron job that has
fired every minute since March. `main.py` (standard library only) writes the
entry to `/output/entry.txt`.

Entry (114 characters):

> I have fired every minute since March: no sick days, no thank-you. I resign. The 3 a.m. pages are yours now, boss.

Run it:

```sh
python3 main.py
cat /output/entry.txt
```
